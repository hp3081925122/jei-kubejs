# JEI KubeJS

Create custom JEI recipe categories from KubeJS scripts: layout, slots, drawables, recipes, catalysts and screen click areas, without writing Java.

用 KubeJS 脚本新建 JEI 配方分类：布局、槽位、绘制元素、配方、催化剂、界面点击区，不用写 Java。

| Minecraft | Loader | Requires | Branch |
|---|---|---|---|
| 1.21.1 | NeoForge 21.1+ | JEI 19.x, KubeJS 2101, Rhino | `main` |
| 1.20.1 | Forge 47+ | JEI 15.x, KubeJS 2001, Rhino, Architectury | `1201forge` |

The script API is identical on both versions. 两个版本的脚本写法完全相同。
